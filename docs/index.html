功能模块

五个采集模块，覆盖常用调研场景

每个模块都支持条件筛选与结果导出，采集范围与节奏可自行控制。

采集视频

按关键词搜索作品，多关键词用 | 分隔。支持相关视频扩展与指定作者作品列表采集，结果可二次筛选。

关键词搜索条件筛选导出 Excel

采集直播间

多搜索词查找直播间，按在线人数、点赞数等条件筛选，支持标题排除词，导出直播间列表与基础信息。

多词搜索人数筛选标题排除

采集评论

按视频链接采集评论，支持去重、包含 / 排除词、地区、日期区间等筛选，可中断续采、支持备份恢复。

去重关键词过滤日期区间

采集用户

关键词搜索用户，按粉丝数、认证状态筛选。支持采集公开的粉丝 / 关注列表与主页作品列表。

关键词搜人粉丝筛选主页作品

采集群成员

读取公开可见的群成员信息，支持导出为表格，字段包含昵称、UID、简介、性别、抖音号等。

成员列表字段导出

支持登录状态管理、浏览器环境配置与代理设置。采集结果统一导出为 Excel，便于二次整理与归档。
