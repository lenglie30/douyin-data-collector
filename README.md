## 👋 软件简介

`抖音公开数据采集器` 是一款面向公开数据整理场景的桌面 GUI 工具，整合了作品采集、评论采集、直播间采集等常用能力。**无需配置 Python 环境**，下载客户端解压后即可运行。

适合以下场景：

| 场景 | 说明 |
| --- | --- |
| ✅ 行业调研 | 按关键词采集相关作品与互动数据，观察内容趋势 |
| ✅ 竞品观察 | 采集指定作者的作品列表与公开数据，做横向对比 |
| ✅ 选题参考 | 整理高互动作品与评论反馈，辅助内容规划 |
| ✅ 数据归档 | 把公开数据导出为表格，便于二次整理与分析 |

## 🚀 快速开始

1. 打开 [Releases](https://github.com/lenglie30/douyin-data-collector/releases/) 下载最新版客户端。
2. 解压后运行客户端（Windows 无需安装其他依赖）。
3. 使用开通后获得的账号登录，首次登录自动绑定当前设备。
4. 选择对应采集模块，填写关键词或链接，设置筛选条件。
5. 点击开始采集，等待完成。
6. 在导出目录查看 Excel 结果文件。

## 🛠️ 技术说明

软件采用客户端本地运行方式，核心特点：

| 特性 | 说明 |
| --- | --- |
| 本地运行 | 采集结果、导出文件与登录状态均保存在本机 |
| 开箱即用 | 已打包为桌面客户端，无需配置运行环境 |
| 断点保留 | 按页写入文件，中途中断已采部分通常仍会保留 |
| 节奏可控 | 采集请求间隔与批次节奏支持调整 |

采集结果不会上传至服务器。授权校验仅用于确认设备使用权。

## ❓ 常见问题

### 客户端从哪里下载？

打开 [Releases](https://github.com/lenglie30/douyin-data-collector/releases/) 下载最新版压缩包，解压后运行。也可进群从群文件获取。

### 是否需要安装 Python 或配置环境？

不需要。软件已打包为桌面客户端，解压后即可运行。

### 采集结果保存在哪里？

默认保存在客户端所在目录，导出为 Excel 文件。

### 采集中断后数据会丢失吗？

按页保存，不是等全部采集结束才写入。即使中途中断，已完成部分通常仍会保留。

### 授权是怎么算的？可以换电脑吗？

授权绑定设备，一个授权对应一台电脑。需要更换设备时联系客服解绑。

### 软件更新需要重新购买吗？

不需要。授权有效期内，后续版本均可免费获取。

### 支持采集多少数据？

实际数量受关键词、账号状态、接口返回、网络环境与采集频率影响。建议合理设置采集范围与请求间隔。

### 软件报错怎么办？

请在反馈时提供：软件版本、操作系统、使用的功能模块、输入的关键词或链接、报错截图。
